## The suite

### Office

| App | What it does | Replaces |
|---|---|---|
| **Docs** | Rich text editing, real-time collaboration, comments, version history, DOCX/PDF export | Google Docs, Word |
| **Sheets** | Formulas, conditional formatting, sorting, charts, XLSX/CSV | Excel, Google Sheets |
| **Slides** | Layouts, themes, fullscreen present mode, PPTX import | PowerPoint, Google Slides |
| **Notes** | Ideas, research and meetings with tags, checklists and doc links | Notion, Google Keep |
| **Forms** | Forms and surveys with sections, validation, live response summary | Google Forms, Typeform |
| **PDF** | Fillable templates — contracts, NDAs, offers. Fill, sign, download | Adobe Acrobat, PDFfiller |
| **Mail** | Threads, labels, attachments, scheduled send, Google/IMAP | Gmail, Outlook |
| **Chat** | Channels, DMs, threads, reactions, teams — realtime | Slack, Teams |
| **Calendar** | Events, meetings and tasks across month/week/day/list views | Google Calendar |

### Business

| App | What it does | Replaces |
|---|---|---|
| **CRM** | Contacts, visual deal pipeline, activity tracking | HubSpot, Pipedrive |
| **Invoices** | Create, send and track invoices with line items and PDF export | FreshBooks, Wave |
| **Books** | Bookkeeping — accounts, transactions, categories, reports | QuickBooks |
| **Signature** | Send for e-signature, track status, legally binding | DocuSign, HelloSign |
| **Sites** | Website builder — 70+ sections, live canvas, one-click publish | Wix, Webflow |
| **Board** | Kanban boards with columns, cards, assignees, labels | Trello, Asana |
| **Records** | Structured records and tables on a local-first engine | Airtable |
| **Teams** | Members, roles, groups, access settings, activity feed | Workspace admin |
| **API** | Developer API and MCP integration for automation | Zapier |

## Principles

- **Local-first** — documents live on your device and work offline
- **End-to-end encrypted sync** — across devices, by architecture
- **Connected, not bundled** — an invoice links to a contact, a form feeds a record
- **No lock-in** — DOCX, XLSX, PPTX, PDF, ODT, CSV and Markdown in and out
- **One price** — the whole suite instead of six separate subscriptions
